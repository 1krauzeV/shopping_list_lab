СПИСОК ПОКУПОК

Приложение для ведения списка покупок. Программа помогает сохранять, отмечать купленные и удалять ненужные товары.

Возможности:
- Добавление товара с названием и положительным целым количеством.
- Просмотр списка покупок.
- Отметка выбранного товара как купленного.
- Удаление выбранного товара с подтверждением.
- Сохранение списка между запусками программы.

Технологии
- Python 3 — логика приложения.
- Tkinter — графический пользовательский интерфейс.
- SQLite (модуль sqlite3) — база данных.
- Git и GitHub — контроль версий.
Используются библиотеки из стандартной поставки Python;
Для запуска нужен Python с поддержкой Tkinter.

Как запустить
1. Установить Python 3 с поддержкой Tkinter.
2. Скачать проект или клонировать репозиторий:
git clone https://github.com/1krauzeV/shopping_list_lab.git
cd shopping_list_lab
3. Запустить программу из папки проекта:
python main.py
4. При первом запуске программа автоматически создаёт файл purchases.db и таблицу purchases. Данные сохраняются на компьютере пользователя. Файл базы данных не загружается в GitHub.

Структура проекта
- main.py — окно программы, кнопки, обработка действий пользователя.
- database.py — создание базы данных и SQL-запросы.
- .gitignore — список локальных файлов, которые Git не отслеживает.
- README.md — описание проекта и инструкция запуска.
Структура базы данных
Таблица purchases содержит четыре поля:
1. Поле id - уникальный номер покупки;
2. name - название товара;
3. quantity - Количество товара;
4. is_bought - статус 0 — не куплено, 1 — куплено.

Основные сценарии использования
1. Добавление покупки: ввести название и количество, нажать «Добавить».
2. Отметка покупки: выбрать строку в списке, нажать «Отметить как купленное».
3. Удаление покупки: выбрать строку, нажать «Удалить выбранный товар», подтвердить удаление.

Ограничения учебной версии
1. Количество вводится положительным целым числом.
2. Отметка «КУПЛЕНО» не переключается обратно на «Нужно купить».
3. Изменение названия и количества уже добавленной покупки не предусмотрено.
